Operator

Shutting down is always allowed from this screen, because it moves the plant to its safe state. Changing the setpoint, resetting a trip or bypassing the shutdown need a signed command from the operator console. This screen cannot do them:

  • Reset after a shutdownmake operator ARGS=reset
  • Change the shutdown temperaturemake operator ARGS="setpoint 85"
  • Maintenance bypass on / offmake operator ARGS="bypass on"
Technical detail

Each command is signed with the operator's ML-DSA-65 key, carries a single-use nonce and a timestamp that must be within 30 s of the server clock. The setpoint is clamped after the signature checks out: 40.0–120.0 °C, at most 15.0 °C per step. A correctly signed request outside that range is refused like an unsigned one.

Closed on this branch. Device identity and handshake authentication use ML-DSA-65 (FIPS 204). A node verifies the server's signature over the encapsulation key before continuing, and the server refuses any handshake it cannot attribute to an enrolled device. Signatures are bound to the role and to both halves of the exchange, so one cannot be replayed into another session.

Long-term signing keys have no forward secrecy Session keys rotate per connection, but the ML-DSA identity keys do not. An attacker who extracts a device's signing key can impersonate it until it is re-enrolled. Mitigation is key rotation and revocation, which this system has no mechanism for.
Single-family cryptographic risk ML-KEM and ML-DSA both rest on structured lattices. A break in that family would take out key exchange and authentication together. NIST selected HQC in March 2025 as a backup KEM on different (code-based) mathematics for precisely this reason; a hybrid ML-KEM + HQC construction would remove the single point of failure.
No side-channel resistance These are reference implementations in pure Python. Constant-time behaviour is not guaranteed, and lattice schemes are known to be sensitive to timing and power analysis on embedded targets. Production deployment needs a hardened implementation such as liboqs or pqm4.
Energy cost is unmeasured on real hardware Timings here are from a laptop. Post-quantum key generation is materially more expensive than ECDH on battery-powered nodes, and published work on embedded energy profiling suggests this dominates the security budget for duty-cycled sensors. Our figures do not capture it.
The dashboard can shut the plant down, and do nothing else The PIN is a screen lock, not access control: anyone who can reach this server can still receive the live events. That is tolerable only because the dashboard holds no authority that reduces safety. Its one control is the manual emergency shutdown, which moves the plant to its safe state. The old setpoint slider and override buttons were removed entirely, together with their server handlers, because a browser has nowhere safe to keep an ML-DSA signing key. Setpoint, reset and bypass live only on the signed operator console. The "Unsigned Control Path" attack sends those old events again and shows that nothing on the server handles them.

Replay was on this list until tested for. Captured packets are now accepted exactly once per session key.
