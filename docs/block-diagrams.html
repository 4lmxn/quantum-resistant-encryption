SIS-01 — every key in the system, and where it comes from

The demonstrator carries four separate key relationships. Three are agreed fresh on every connection; one is provisioned at commissioning and never enters the source. The difference between them decides what each link is allowed to do. Nothing here is a fixed secret hiding in the repository — every key is either generated per session or provisioned at runtime. These diagrams show all four, and every signature that protects them.
